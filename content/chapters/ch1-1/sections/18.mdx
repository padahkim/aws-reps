객체를 호출자에게 반환하기 **직전에 Lambda로 변환**합니다. 변환본을 위한 별도 버킷 복제가 필요 없습니다. 구성 순서: **S3 버킷 → (지원) 액세스 포인트 → Object Lambda 액세스 포인트 → Lambda → 애플리케이션**.

사용 예: 분석 환경용 **PII 마스킹/삭제** · XML→JSON 등 **포맷 변환** · 요청자별 **이미지 리사이즈·워터마크** · 다른 소스 정보를 합치는 **데이터 보강**. GET 외에 HEAD·LIST 요청 변환도 지원합니다.

<Note>부기: 2025-11-07부터 S3 Object Lambda는 <b>기존 사용 고객과 일부 APN 파트너 전용</b>입니다. 신규 온보딩이 막혔고 새 기능 추가 계획도 없으며(보안·가용성 개선만 유지), 대체 경로는 CloudFront·API Gateway·Lambda 함수 URL로 Lambda를 직접 호출하거나 클라이언트에서 처리하는 방식입니다. 시험 선지로는 여전히 등장하므로 개념은 그대로 익혀 둡니다.</Note>
