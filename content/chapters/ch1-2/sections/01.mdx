서버리스는 “서버가 없다”가 아니라 <b>서버를 관리·프로비저닝하지 않는다</b>는 뜻입니다. Lambda에서 개척되어 지금은 관리형 전반(DynamoDB, S3, API Gateway, Cognito, SQS, Step Functions, Fargate 등)을 포괄합니다. 예를 들어 AWS가 자주 예시로 드는 <b>표준 서버리스 웹앱</b>은 이렇게 조립됩니다: 정적 화면(HTML·JS)은 <b>CloudFront + S3</b>가 배포하고, 로그인은 <b>Cognito</b>가 처리하고, 데이터 요청은 <b>API Gateway가 받아 Lambda를 호출하고 Lambda가 DynamoDB를 읽고 쓰는</b> 경로로 흐릅니다. EC2 서버 한 대 없이 웹앱 전체가 완성되는 구성입니다.

과금 = <b>요청 수 + 컴퓨팅 시간(GB-초 = RAM×초)</b>. 프리 티어 월 100만 요청 + 40만 GB-초, 초과 시 요청 $0.20/100만 건. 함수당 최대 10GB RAM이며 <b>RAM을 늘리면 CPU·네트워크 성능도 함께 향상</b>됩니다(시험 단골). 런타임: Node.js, Python, Java, .NET, Ruby + Custom Runtime API(Rust, Go 등).
