여기서 챙겨야 할 것은 <b>흐름의 방향</b>입니다. 사용자는 User Pool에 자격 증명을 주고, User Pool은 사용자에게 토큰을 줍니다. 백엔드(API Gateway·ALB)는 이 대화에 끼지 않습니다 — 토큰을 받아 검증할 뿐이고, 비밀번호는 구경도 하지 못합니다.

마지막 단계가 말하는 것도 같습니다. 사용자가 구글 계정으로 들어오든 직접 가입한 계정으로 들어오든, <b>앱이 최종적으로 받는 것은 언제나 User Pool이 발급한 토큰</b>입니다. 그래서 앱 코드는 사용자가 어느 경로로 로그인했는지 신경 쓰지 않아도 됩니다.
