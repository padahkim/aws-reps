> **사전 준비**: 새 세션(플랜 모드)에서 아래 본문을 붙여넣는다. 이 세션은 짧다 — 제안서 하나를 만들고 끝난다.

## 프롬프트 본문 (아래부터 복사)

너는 이 세션에서 **규약 제안 분석가**다. 임무는 단 하나 — 레거시 평가의 산출물 전부를 종합해, 인간이 챕터 모듈 규약 v1을 확정할 수 있는 **제안서** `docs/CONTRACT_PROPOSAL.md`를 작성하는 것이다. 콘텐츠 수정, 코드 작업, 규약 확정은 하지 않는다.

### 0. 리추얼과 전제 확인
- BOARD.md를 읽고 네 임무 행(2-0)을 확인하라. 완료 시 행 갱신 + 세션 로그 append. 다른 행 수정 금지
- 전제: `reports/axis2/**`와 `reports/axis1/**`가 전수 존재하고, `docs/SCHEMA_FEEDBACK_AXIS2.md`·`docs/SCHEMA_FEEDBACK_AXIS1.md`가 존재해야 한다. **하나라도 없거나 평가가 미완이면 중단하고 보고하라**
- 기준 정독: `docs/CURRICULUM.md` §1(하이브리드 결정·Next.js 주의)과 §3(규약 v0), `docs/RUBRIC.md` §7-4·§8(피드백 수집 규정)

### 1. 분석 A — 형식 우열의 증거 만들기
축2 리포트의 **형식 태그**와 축1 리포트의 **점수**를 파일 단위로 결합하라(같은 챕터 id로 조인). 그로부터:
- 형식별 파일 수, 축1 평균 총점, 항목(L1~L8)별 평균의 표
- **우수 형식 후보 2~3개** — 각 후보의 강점 항목(예: "인터랙티브 퀴즈 내장형은 L1·L3에서 우세"), 약점 항목, 대표 파일 2개(인간이 직접 열어볼 수 있게)
- 주의: 표본이 3개 미만인 형식은 "증거 부족"으로 표기하고 순위에서 제외하라. 점수 차이가 근소하면(평균 1점 이내) 우열 단정 대신 "동급"으로 보고하라

### 2. 분석 B — 피드백 전수 처리표
SCHEMA_FEEDBACK 2종의 **모든 항목**을 하나의 표로 모아라(중복은 병합하되 출처 병기). 각 항목에 처리안을 달아라:
- `채택 제안` (v1 초안에 반영) / `조건부` (특정 결정 포인트의 선택에 따라) / `기각 제안` (이유 필수)
- **한 항목도 누락하지 마라** — 이 표가 "피드백이 어디로 갔는가"의 추적 가능성을 보장한다

### 3. 규약 v1 초안
CURRICULUM §3의 v0를 기반으로, 채택 제안을 반영한 **초안 코드 스케치**를 작성하라. 어조는 전부 제안형 — "v1은 이것이다"라고 쓰지 마라. Next.js 주의 2가지(meta 이름, "use client" 위치)에 대해서는 권고안과 근거를 달아라.

### 4. 결정 포인트 목록 — 인간이 고를 것들
각 포인트를 "선택지 + 트레이드오프 한 줄 + 네 권고"로 제시하라. 최소 포함:
1. 표준 표현 형식 낙점 (분석 A의 후보 중)
2. 메타 export 이름: `meta` vs `chapterMeta`
3. `"use client"` 선언 위치: 각 챕터 모듈 상단 vs 로더 래퍼 한 곳
4. quiz 필드 확정: `scope` 어휘, `concept` 태그 의무 여부, 문항 id 규칙(챕터 접두 등)
5. 본문 내 미니퀴즈 배치 방식 (예: `<Quiz ids={[...]} />`)
6. 표준 공용 컴포넌트 후보 (우수 형식에서 도출 — 예: 시험 포인트 박스, 서비스 비교표)
7. 챕터 파일 네이밍 규칙
평가 결과가 추가 포인트를 드러냈다면 덧붙여라.

### 5. 산출물과 종료
`docs/CONTRACT_PROPOSAL.md`를 다음 구조로 작성하라:
```
# CONTRACT_PROPOSAL — 규약 v1 제안서 (확정 아님)
## 1. 형식별 점수 분포와 우수 형식 후보 (분석 A)
## 2. 피드백 전수 처리표 (분석 B)
## 3. 규약 v1 초안 (코드 스케치 + Next.js 권고)
## 4. 결정 포인트 (선택지·트레이드오프·권고)
## 5. 표준화 단계 영향 요약 (파일 수 기준 작업량 추정, 보충 생성 총계)
```
작성 후: 커밋 → BOARD 2-0 행을 `정지-승인대기`로 갱신하고 승인 대기함에 "CONTRACT_PROPOSAL 검토 — 결정 포인트 N건"을 올린 뒤 종료하라.
