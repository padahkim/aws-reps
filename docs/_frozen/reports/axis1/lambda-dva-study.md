## 수정 지시

1. **[L1 상향, 1→2 여지]** 퀴즈 10문항을 `ChQuiz` 말단 단일 섹션에서 각 개념 챕터(`ChOverview`/`ChInvoke`/`ChConcurrency`/`ChVersions`/`ChConfig`) 직후로 **분산 재배치**. 예: 콜드스타트 시뮬레이터(`LifecycleSim`) 직후에 Q3(예약 트래픽 콜드스타트) 배치, `ChConcurrency` 직후 Q4(429 스로틀). 문항 품질은 이미 적용형이라 배치만 고치면 L1이 2로 상향.
2. **[L3 상향, 1→2]** 각 개념 블록에 실전형 예시를 개념-직후 결합. 예: `ChConfig` QUOTAS 표 밑에 `aws lambda update-function-configuration --memory-size 1769` CLI 한 줄, `PermDiagram` 옆에 리소스 기반 정책 JSON 골격 1개, 핸들러 시그니처 코드 골격 1개. 지문이 코드 판독형으로 나올 때 대비.
3. **[L6 상향, 1→2]** `PermDiagram`에 "0-2 IAM의 신뢰 정책이 Lambda 실행 역할의 `sts:AssumeRole`로 적용" 명시 지목 추가.

## 보충 생성 목록 (결손 성분)

- **[해설 성분]** 자유서술 자가채점 구조라 오답 조건화 해설이 없음. 스키마 v1에서 `type: recall` 문항이라도 "핵심 채점 기준 + 흔한 오답 함정" 텍스트를 모범답안에 병기하도록 보강(L2는 N/A로 두되 학습 효과 보강 차원).
- **[커버리지 위임 — 축2 소관]** Lambda VPC 통합(ENI/서브넷/콜드스타트 영향) 개념 카드/도식 추가는 축2 수정 지시 1·2번 소관. 축1은 신규 블록에 위 L1·L3 개선 패턴 동시 적용 권고.

## 반복 약점 메모

- **문항 말단 집중(L1)**: 우수한 적용형 문항을 챕터 끝에 몰아 인출 밀도가 희석되는 패턴. A2 완화 대상이지만 근본 해법은 분산 배치. 생성 프롬프트에 "각 개념 블록 직후 1문항 인접 배치" 규칙 반영.
- **코드 예시 부재(L3)**: 시뮬레이터·도식은 강하나 CLI/코드/JSON 결손 → 코드 판독형 지문 대비 약함. messaging·template과 공통 약점.
- **L6 선행 브리지 부재**: 3개 캘리브레이션 파일 전부 L6=1. 코퍼스 전반 반복 예상 — 생성 프롬프트 공통 체크리스트 격상 확정 권장.

## 스키마 피드백 요약

- 기존 B3(`type: recall` 자유서술 자가채점)·B6(인터랙티브 시뮬레이터) 근거 파일. 재확인, 신규 항목 없음. A1·A2·A3 앵커 자체가 이 파일에서 도출됐으므로 SCHEMA_FEEDBACK_AXIS1 A1~A3 섹션과 교차 참조.
