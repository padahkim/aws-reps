## 수정 지시

1. **[L5, 챕터 경계]** §05 CloudShell(0-1 인접 주제)을 0-1 문서로 이관하거나 "0-1 참조" 링크로 축약 → L5 1→2. iam_guide와의 중복도 변환 단계에서 통합(이 파일을 0-2 정본으로, iam_guide의 `EvalEngine` 시뮬레이터를 흡수 권장).
2. **[L6 상향, 1→2]** §advanced "IAM 정책 & S3 버킷 정책 합산"에 "1-1 S3 버킷 정책과 동일 리소스 기반 메커니즘" 챕터 지목, §roles에 "0-1 자격증명 프로바이더 체인의 롤 단계" 역참조 추가.

- **[퀴즈·해설 결손]** L1·L2·L7·L8 N/A 원인. §advanced(415강, 최빈출)의 "정책 평가 4문형" 표를 **그대로 4지선다 문항으로 전환**(각 케이스가 이미 시나리오→정답 구조). `iam:PassRole`("역할 전달했는데 서비스가 못 씀 → 신뢰 정책 Principal 확인") 콜아웃도 문항화. §30강 체크리스트 문항화.
