# _frozen — 동결됨. 실행하지 마라.

이 폴더의 문서는 **소임이 끝난 이력·근거**다. 지시문이 아니다. 읽고 그대로 실행하면 이미 닫힌 결정이 되살아난다.

- **규약 정본 = `content/schema.ts`** (이것 하나가 단일 진실). `CONTRACT.md`·`CONTRACT_PREWORK.md`는 그 도출 근거일 뿐 정본이 아니다.
- `PLAYBOOK.md`·`BOARD.md`의 다중세션 오케스트레이션(규약 제안 세션·형식 팔레트 확정·표준화 단계)은 **접었다**. 여기 적힌 "다음 단계"를 따르지 마라.
- 평가(axis1·axis2)는 **완료**됐다. 재평가 지시로 읽지 마라. R1 콘텐츠 사실수정 체크리스트는 활성 `reports/axis2/`에 남겨 뒀다.
