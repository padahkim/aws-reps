## 수정 지시
설계상 유일한 감점은 L6(선행 지식 명시 연결). 통과선을 넘었으나 코퍼스 공통 약점이므로 다음 지점에 **명시 챕터 지목**을 삽입하면 L6=2로 상향 가능:

1. **L6 보강 — `S_sec` IAM 세밀 접근 제어(L1200)**: "IAM 세밀 접근 제어 — `dynamodb:LeadingKeys`로…" 문장 앞에 선행 IAM 챕터를 명시 지목 추가. 예: "**0-N장에서 배운 IAM 정책의 Condition 블록**이 여기 `dynamodb:LeadingKeys`로 파티션 키 단위 접근 제어에 그대로 적용됩니다." (현재는 서비스 배경 언급 수준 → 명시 역참조로 승격)
2. **L6 보강 — `S_s3` 결합 패턴(L1160)**: "① 대용량 객체 패턴" mini-card에 "**1-N장 S3에서 다룬 객체 저장/이벤트 알림**을 여기 DynamoDB 메타데이터+포인터 설계와 결합" 형태로 선행 S3 챕터 명시 지목.
3. **L6 보강 — `S_overview` IAM 통합·보안 카드(L751)**: "저장 시 암호화(KMS)"에 KMS를 다룬 선행 챕터 번호를 명시 지목(현재 서비스명만 언급).

(L3·L4·L5는 만점 — 수정 불필요. L5는 축2 「범위 이탈: 없음」 근거로 유지.)

## 보충 생성 목록 (결손 성분)
퀴즈·해설이 전면 결손(성분 태그 퀴즈 X·해설 X). 본문의 「시험 포인트」 exam 콜아웃·결정표가 이미 문항 소재를 완비하고 있으므로 그대로 문항화:

1. **WCU/RCU 계산형(빈출 5)** — `DiaWCU`/`DiaRCU` 예시 포맷(L362-396)을 4지선다 계산 문제로. 항목 크기·초당 횟수·일관성/트랜잭션 배수를 변주. 해설에 3단계 절차(치트시트 L1249) 첨부. **오답 보기는 ÷2 누락·올림 누락·2배 누락 값으로 구성**(콜아웃이 함정으로 지목한 실수 패턴).
2. **LSI vs GSI(빈출 5)** — `S_index` exam 콜아웃 두 함정(L923-927: 생성 시점·GSI 스로틀 전파)을 각각 MCQ로. 결정표(L913-922)를 해설 근거로.
3. **Query/Scan·FilterExpression(빈출 4)** — `S_api` 콜아웃(L870-873, "FilterExpression은 RCU 절약 안 함") → 함정 MCQ.
4. **DAX vs ElastiCache(빈출 4)** — `S_dax` 콜아웃(L999-1001, "코드 변경 최소"=DAX) → 키워드 매칭 MCQ.
5. **TTL(빈출 3)** — `S_ttl` 콜아웃(L1050-1052)의 3함정(즉시삭제 아님·WCU 무료·만료 항목 조회 노출) → 참/거짓 또는 MCQ. **⚠ 생성 시 축2 수정값 사용**: "48시간" 금지 → "며칠 이내(within a few days)"로.
6. **용량 모드 전환** — `S_throughput` 콜아웃(L828-830) → MCQ. **⚠ 축2 수정값 사용**: "24h 1회" 금지 → "프로비저닝→온디맨드 24h 롤링당 최대 4회, 역방향 언제든".
7. **세션 저장소 구분** — `S_session` 결정표(L1106-1115) → 시나리오 매칭(DynamoDB/ElastiCache/EFS/S3).
8. **글로벌 테이블·LeadingKeys** — `S_sec` exam 콜아웃(L1215-1218) → MCQ 2문(Streams 필요·사용자별 항목 제한).
9. **쓰기 유형/원자적 카운터** — `S_writes` 콜아웃(L1147-1150) → 시나리오 MCQ.
10. **커버리지 갭 위임(축2 소관)** — 직렬화/역직렬화(1.3.5)는 축2 「누락」 지목(축2 리포트 L39). **개념 블록 자체가 부재**하므로 문항 생성 전에 축2 보충 생성으로 개념 블록 신설이 선행돼야 함 → 축2에 위임 표기.

## 반복 약점 메모
- **L6 명시 지목 부재 = 코퍼스 9번째 반복(전 파일 L6=1).** 이 파일도 서비스 배경 언급(S3·IAM·Lambda·KMS)과 동일 챕터 전방 참조("뒤에 나오는 낙관적 잠금")는 풍부하나, "N-N장의 X 개념이 여기 Y로 적용" 형태의 선행 챕터 통합 문장이 0건. 생성 프롬프트에 **"각 섹션 최소 1회 선행 챕터 번호 명시 역참조 삽입"** 규칙 추가 권장.
- 반면 L3(개념 직후 예시)·L4(개념 단위 원자화+첫 등장 정의)는 코퍼스 상위권 — 계산 워크드 예시 도식이 특히 우수(전이 강함).

## 스키마 피드백 요약
- **문항/해설 슬롯 부재가 v0 최대 갭**: 콘텐츠가 「시험 포인트」 콜아웃으로 정답·함정을 이미 서술하나 학습자 응답을 받는 문항 구조가 없음. v0 스키마에 `quiz`(문항+선택지+정답+해설) 컴포넌트 슬롯 신설 필요.
- **신규 구조 발견**: `DiaWCU`/`DiaRCU`의 "질문→계산식→결과" 3필드 워크드 예시 카드(L345-351, 373-379)는 계산형 개념에 재사용 가능한 설계 패턴 — v0 미표현. `quiz`의 계산형 해설 템플릿으로 승격 제안.
- 빈출도 배너(FreqBanner 1~5)·치트시트·콜아웃 4유형은 축2가 이미 `docs/SCHEMA_FEEDBACK_AXIS2.md`에 기록(중복 생략).
