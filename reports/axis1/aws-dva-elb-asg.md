## 수정 지시

L6이 유일 감점(1→2 목표). 아래 3지점에 **선행 챕터·개념 명시 역참조**를 삽입:

1. **`S_ELB` 보안 그룹 섹션(L1868, "EC2 보안 그룹: 인바운드 소스를 ELB의 보안 그룹으로 지정")** — 앞의 EC2 보안 그룹 챕터를 명시 지목. 예: "4-0 EC2 보안 그룹에서 배운 '소스로 다른 SG를 참조' 규칙이 여기 ELB→EC2 인바운드에 그대로 적용된다"로 확장.
2. **`S_ASG` 시작 템플릿 항목(L2311-2313, "AMI + 인스턴스 타입, EBS 볼륨, 보안 그룹, 키 페어, IAM 역할, User Data …")** — 이 구성요소들이 선행 EC2 챕터 산출물임을 명시. 예: "이 항목들은 4-0 EC2 기초에서 개별로 다룬 요소를 시작 템플릿 하나로 묶은 것"이라는 역참조 문장 추가.
3. **`S_HA` 확장 대상 표(L1758, "RDS, ElastiCache 같은 비분산 시스템")** — 수직 확장 대상으로 RDS/ElastiCache를 들 때 해당 데이터 계층 챕터를 명시 지목(예: "N-N장 RDS Multi-AZ"). 현재는 서비스명만 나열이라 L6=1에 머문다.

## 보충 생성 목록 (결손 성분)

퀴즈·해설 전면 결손이 핵심 산출물. 각 섹션의 Exam 콜아웃·결정표를 **문항 소재**로 전환(선택지+정답+오답 해설 부착). 개념 블록 → 생성 문항:

- **S_ELB(보안그룹)**: "EC2가 ELB 경유 트래픽만 받게 하려면?" — 선택지 [A) 0.0.0.0/0 허용 B) ELB의 SG를 소스로 참조 C) ELB IP CIDR 하드코딩]. 오답 해설: IP는 변동하므로 SG 참조가 정답. 소재 = Exam L1873-1877.
- **S_ALB**: "백엔드에서 클라이언트 실제 IP 획득 방법" → X-Forwarded-For (소재 L1986-1990); ECS 동적 포트 매핑 + ALB 조합 문항.
- **S_NLB**: "고정 IP 화이트리스트 + TCP/UDP 극한 성능" → NLB; "고정 IP인데 L7 규칙 필요" → NLB→ALB 조합 (소재 L2030-2034). ⚠️ 문항 생성 시 축2 지시대로 "프리 티어 미포함" 문구 정정본 사용, 지연 100ms 수치는 문항화 금지.
- **S_GWLB**: "GENEVE :6081" / "방화벽·IDS 선통과 검사" → GWLB (소재 L2059-2063).
- **S_STICKY**: 커스텀 쿠키 예약어(AWSALB/AWSALBAPP/AWSALBTG) 사용 불가 판별 문항 (소재 L2126-2130).
- **S_CROSS**: "ALB 기본 ON·무료 / NLB 기본 OFF·유료" 조합을 뒤섞은 4지선다 (소재 결정표 L2149-2169).
- **S_SSL**: "한 LB에서 여러 도메인 다른 인증서" → SNI(ALB·NLB·CloudFront, CLB 불가) (소재 L2233-2237).
- **S_DRAIN**: "제거 인스턴스에서 진행 요청 끊기지 않게" → Deregistration Delay 기본 300초·1~3600·0=비활성 (소재 L2267-2271).
- **S_ASG**: "unhealthy 자동 교체" → ASG+ELB 헬스체크 연동; min/desired/max 의미 문항 (소재 L2337-2342).
- **S_POLICY**: 4종 정책 매칭 세트 — 대상추적(최간단)/RequestCountPerTarget/Cooldown 300초/예약 스케일링 (소재 L2409-2415).
- **S_REFRESH**: "무중단 새 AMI 배포" → Instance Refresh + Min Healthy % (소재 L2441-2445).
- **해설 성분**: 위 각 문항에 오답별 조건화 해설 부착(L2 앵커 충족을 위해 4지선다 형태 권장). S_SUMMARY의 암기 카드 표(L2474-2503)를 cloze/자가채점 소재로 활용.
- **커버리지 갭**: 축2 「누락 없음」·「표면 커버 없음」 → 콘텐츠 커버리지 위임 불필요.

## 반복 약점 메모

- **L6 명시 지목 부재 — 코퍼스 9연속 L6=1.** 선행 서비스(EC2 SG·EBS·IAM·RDS)를 배경 이름으로만 호명하고 "N-N장/특정 선행 개념"으로 명시 통합하지 않는 패턴이 이 파일에서도 반복. 생성 프롬프트에 "선행 챕터 최소 1회 명시 역참조(장 번호+개념) 삽입" 지시를 표준 항목으로 추가 권장.
- messaging과 동형 프로파일(설명·다이어그램·시험포인트 견고, 퀴즈 결손, L3~L5 만점, L6만 감점) 재확인 — 다이어그램 중심 개념 파일이 축1 설계 품질은 안정적으로 높되 능동 인출(퀴즈)·선행 통합에서 공통 결손.

## 스키마 피드백 요약

- `Freq`(빈출도 뱃지)·`Exam`(시험 포인트)·시나리오→정답 요약표·암기 카드 패턴은 축2가 dynamodb·ec2-guide 계열 반복으로 이미 기록(중복 등재 생략).
- **축1 관점 신규 1건**: S_SUMMARY의 "암기 카드" 표(항목→핵심 값 2열, L2474-2503)는 간격반복·자가테스트 소재로 이상적 구조이나 현재 정답 노출형(수동 읽기). 이를 **cloze/자가채점 문항으로 자동 전환 가능한 "정답 은닉 토글" 구조**가 v0 스키마에 미표현 — 퀴즈 결손 파일 다수에서 최소 비용으로 능동 인출 성분을 확보할 후보 패턴으로 기록 권장.
