## 보충 생성 목록 (결손 성분)

- **[퀴즈·해설 결손]** §05 평가 로직(최다 출제)·§06 Role/STS·§04 정책 유형에 정책 JSON 판독형 적용 문항 + 오답 조건화 해설 신규 생성. `EvalEngine` 토글 조합이 문항 소재(예: "관리자 Allow* + SCP Deny → 결과? 왜?")로 직접 전환 가능. §08 치트시트 8항도 문항화 가능.
- **[커버리지 — 축2 소관]** STS API 4종(AssumeRole/WithWebIdentity/WithSAML/GetSessionToken)은 §06 Note에 이름은 있으나 개별 용도·구분 심화는 축2 보강 지시 참조.
