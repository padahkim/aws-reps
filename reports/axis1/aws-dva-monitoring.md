## 수정 지시

L3·L4·L5는 만점. 유일 감점은 L6.

1. **L6 위반(유일 감점) — 명시적 선행 챕터 역참조 부재.** 현재 IAM·SNS·Kinesis는 서비스 이름 배경으로만 등장. 다음 지점에 선행 챕터 명시 지목을 삽입하면 2로 상향 가능:
   - `SAgent` IAM 인스턴스 역할 불릿(674, "에이전트가 CloudWatch에 쓰려면 IAM 권한(인스턴스 역할)…") → "**2장 IAM에서 배운 EC2 인스턴스 프로파일/역할**이 여기 에이전트의 쓰기 권한으로 그대로 적용된다"로 선행 챕터 명시.
   - `SXray` ②카드(1063, "각 앱·서비스에는 X-Ray에 쓸 IAM 권한이 반드시 필요") → "**2장에서 다룬 실행 역할(AssumeRole)**에 `AWSXRayDaemonWriteAccess`를 부여" 식으로 앞 개념 지목.
   - `SFilters` 파이프라인(738–753, 지표→경보→SNS) → "**메시징 챕터(SNS)**에서 배운 팬아웃이 여기 경보 알림 대상으로 연결된다" 식 역참조.

## 보충 생성 목록 (결손 성분)

**퀴즈·해설 전면 결손이 핵심 결손.** 각 섹션의 `Tip`("시험 포인트") 콜아웃과 `SCompare`의 시나리오→정답 표가 이미 문항 소재로 완성돼 있어 채점형 문항으로 전환 비용이 낮음. 생성 우선순위:

- **주석 vs 메타데이터**(1138–1159, 빈출 매우높음): "user_id로 트레이스를 필터링하려면?" 4지선다(주석/메타데이터/샘플링 규칙/서브세그먼트) + 해설(인덱싱 여부).
- **로그 실시간 vs 배치**(626–635 비교표): "여러 계정·리전 로그를 준실시간 집계" → 구독→KDS→Firehose 선택 문항. 함정: Export Task(배치 12시간) 오답지 포함.
- **메트릭 필터 소급 미적용**(759): "필터 생성 전 로그가 집계 안 됨" 참/거짓 + 해설.
- **경보 상태·대상**(786·800–810): OK/INSUFFICIENT_DATA/ALARM 3종, 대상 EC2작업/ASG/SNS 매칭 문항.
- **X-Ray 트레이스 안 보임 체크리스트**(1067–1077): EC2/Lambda별 원인 순서(IAM→데몬→SDK→Active Tracing) 순서배열형.
- **Fargate=사이드카만**(1284–1288·1321–1325): "인스턴스에 데몬 설치" 오답지 포함 4지선다.
- **CloudTrail 이벤트 3종**(1363–1377): 관리(기본O)/데이터(기본X)/Insights 매칭.
- **X-Ray 샘플링 계산**(1177–1191): "초당 100요청, reservoir 1·rate 5% → 기록 트레이스 수?" 계산형(≈6).

**커버리지 갭(축2 소관 — 축2로 위임)**: EMF(Embedded Metric Format) 개념 블록 전면 결손(5-1 필수 요소), CloudWatch 대시보드 위젯/구성 표면 커버, SCompare에 AWS Config 부재. 이는 축2 수정 지시 1~5로 이미 이관됨 — 축1 설계 감점엔 미반영(사실·커버리지 소관).

## 반복 약점 메모

- **L6 명시 지목 부재가 코퍼스 공통 패턴(지금까지 9개 파일 연속 L6=1).** 이 파일도 예시·다이어그램(L3=2)·부하관리(L4=2)는 모범적이나 선행 챕터 통합 링크가 전무. 생성 프롬프트에 "각 서비스가 앞선 어느 챕터의 개념(IAM 역할·SNS 팬아웃·Kinesis 등)을 재사용하는지 'N장에서 배운 X' 형태로 최소 2회 명시" 지시를 추가하면 코퍼스 전반 L6이 2로 올라갈 여지.
- 반대로 이 파일은 **L3 예시 인접성의 모범 사례**: 모든 개념 블록이 SVG Dgm 또는 코드와 즉시 인접, Tip이 시나리오→정답으로 실전 지문을 선제 노출. 생성 골든 샘플로 삼을 만함.

## 스키마 피드백 요약

신규 없음. 빈출도 배지(1~4단계 막대)·SVG 아키텍처 다이어그램(Dgm/Box/Arw)·"시험 포인트" Tip·시나리오→정답 매핑표·색상 언어 범례는 축2 스키마 피드백(SCHEMA_FEEDBACK_AXIS2.md 제안)에서 이미 포착됨. 축1 관점 추가: `SCompare`의 시나리오→정답 표는 **채점형 문항의 직전 형태(스캐폴딩)**로, v0 스키마에 "quiz-seed" 태그로 이 콜아웃을 문항 자동 생성 소스로 명시하면 퀴즈 결손 보충이 체계화됨.
