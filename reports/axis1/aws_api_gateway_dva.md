## 수정 지시

L3·L4·L5는 이미 만점. 축1 점수 개선의 유일한 지렛대는 **L6(명시 역참조)**. 아래 지점에 "N-N장/선행 개념" 지목을 추가하라(챕터 번호는 커리큘럼 확정본에 맞춰 삽입):

1. **L6 위반 — `Stages` Stage변수→Lambda alias (L833-836)**: "대표 활용: Stage 변수 → Lambda alias 지정" 문장에 **Lambda 챕터의 버전·alias 개념 명시 지목** 추가 (예: "N-N장에서 배운 Lambda 버전/alias를 여기 Stage 변수로 선택 — 코드 재배포 없이 alias만 전환"). 현재는 alias 개념을 선행 학습으로 연결하지 않음.
2. **L6 위반 — `Auth` Resource Policy (L1656-1659)**: "Lambda 리소스 정책처럼 API에 부착"의 "~처럼"을 **명시 역참조로 승격** (예: "N-N장 Lambda 리소스 기반 정책과 동일 메커니즘 — 신뢰 주체를 리소스에 직접 명시"). SigV4(L1652)도 IAM/보안 챕터 지목 권장.
3. **L6 보강 — `Monitoring` X-Ray (L1500-1519)** 및 **`WebSocket` connectionId 저장 (L1960-1961)**: 각각 "N-N장 X-Ray Active Tracing", "N-N장 DynamoDB" 선행 챕터를 명시 지목하면 L6 근거 누적. (동일 챕터 내부 모듈 링크는 L6 무효이므로 반드시 **선행 챕터**를 지목할 것.)

> 주: 축2 소관 사실 수정(로그 레벨 ERROR/INFO/DEBUG → Off/Errors only/Errors and info; REST vs HTTP 표 HTTP 칸에 IAM 추가)은 축1 재론 대상 아님 — 축2 「수정 지시」 1·2 참조.

## 보충 생성 목록 (결손 성분)

**퀴즈·해설 전면 결손이 핵심 갭.** 본 파일은 "exam" 콜아웃·결정표가 이미 문항 소재로 완성형이므로 그대로 채점형 문항으로 전환하라(각 문항에 **해설 필수**):

- **엔드포인트 유형** — `Overview` exam 콜아웃(L707-711)을 3지선다 시나리오로: "전 세계 사용자 지연 최소화 / VPC 내부 전용 / 엣지 캐싱 직접 관리" → Edge / Private+Resource Policy / Regional+CloudFront.
- **통합 유형** — `Integration` exam 콜아웃(L1130-1135): "body/파라미터를 백엔드 전 변형" vs "최대 단순 프록시" vs "SOAP/XML→REST" → 비-Proxy+VTL / Lambda Proxy / 매핑 템플릿.
- **Lambda Proxy 응답 형식** — warn 콜아웃(L1072-1081): "형식 미준수 시 반환 코드?" → **502 Bad Gateway** (해설: statusCode/headers/body/isBase64Encoded 구조).
- **인증 4방식** — `Auth` 결정표(L1741-1768) 4개 행이 그대로 4문항 뱅크(내부 계정→IAM / 교차계정·IP→Resource Policy / 앱 사용자·코드없음→Cognito / 서드파티 토큰→Lambda Authorizer). "Cognito는 인증만·인가는 백엔드" 함정(L1770-1775)을 오답 유도지문으로.
- **사용 계획·Throttle** — `Usage`(L1414, L1418-1422): "속도 초과 응답 코드?" → **429**; "고객별 호출 한도/티어" → Usage Plan+API 키(x-api-key).
- **캐싱** — `Caching`(L1281-1316): 기본 TTL 300초·범위 0~3600·TTL=0=미캐시; "InvalidateCache 권한 미강제 시 아무나 max-age=0으로 무력화" 함정.
- **REST vs HTTP** — 비교표(L1794-1846) 기능별 지원여부 매칭 문항.
- **WebSocket** — @connections push 방법·route selection expression(L1980-1985).

**축2 소관 커버리지 갭(위임 표기)** — 축1 문항 생성 시 함께 보강 권고: 상태 코드 오버라이드(Task 1.1), 오류 코드 표(400·403·429·502·503·504), 통합 타임아웃 기본 29초→504, 페이로드 10MB 한도. (축2 「Task 커버리지」·「수정 지시」 3·6 참조 — 콘텐츠 보충은 축2 소관.)

## 반복 약점 메모

- **L6 명시 지목 부재** — 코퍼스 9번째 연속 감점(앞선 8개 전부 L6=1). 본 파일도 Lambda·Cognito·DynamoDB·X-Ray·CloudFront·Route53·ACM·WAF를 다수 언급하나 전부 "서비스명 배경/~처럼" 수준. 생성 프롬프트에 **"타 서비스 언급 시 해당 선행 챕터 번호를 명시 역참조하라(동일 챕터 내부 링크 불가)"** 규칙 상시 주입 필요.
- 반대로 **L3·L4는 코퍼스 상위** — 원자화 섹션 + 개념직후 도식/시나리오 콜아웃 + 상황→선택 결정표 패턴이 L3=2·L4=2를 안정적으로 확보. 이 구조를 생성 템플릿 기본형으로 승격 권장.
