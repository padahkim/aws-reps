## 수정 지시

1. **[축2 소관 — 종합 게이트]** `SectionConnect` "⚠ 주의" 문단(2353~2356행)의 "VPN이나 DX로 연결해도 VPC 엔드포인트에는 접근할 수 없다" 일반화 오류를 축2 수정 지시대로 게이트웨이/인터페이스 엔드포인트 구분으로 교체. 이 문장이 "시험 함정"으로 제시돼 있어 오류 상태로 학습 시 역효과. (엔드포인트 비교표 2291행에 "온프레미스(VPN/DX) 접근: 게이트웨이=불가/인터페이스=가능" 행 추가.)
2. **[L6 상향, 1→2]** 파일을 유지한다면(인간 결정) 각 개념에 인접 챕터 브리지 추가 — 엔드포인트→"1-1 S3·1-3 DynamoDB의 프라이빗 접근", 보안그룹→"0-2 IAM과 별개인 네트워크 계층 통제", Flow Logs→"5-1 CloudWatch Logs 전송".

## 보충 생성 목록 (결손 성분)

- **[퀴즈·해설 전면 결손]** L1·L2·L7·L8 N/A 원인. 파일 유지 시, 각 비교표의 "시험 단서" 행을 4지선다 문항으로 직접 전환(NACL vs SG DENY, 게이트웨이 vs 인터페이스 엔드포인트, VPN vs DX, 피어링 비전이성). **단, 수정 지시 1의 엔드포인트 접근성 오류 수정 후 문항화**(현 오류를 정답으로 굳히지 않도록).
- **[메타 결정 — 인간 확정(a)]** 존치 = **부록/보너스로 격리**(2026-07-14). 변환 단계에서 VPC를 정규 챕터가 아닌 부록/보너스 트랙으로 배치. 시험 out-of-scope이므로 정규 진도·누적 복습(L8)·시험 우선순위에서 제외하되 참고 자료로 유지.

## 반복 약점 메모

- **퀴즈·해설 부재** → L1·L2·L7·L8 N/A (코퍼스 공통).
- **L6 명시 지목 부재** → 코퍼스 전역 반복(전 파일 L6=1).

## 스키마 피드백 요약

- **[앵커 A5 — 인간 확정(b), 2026-07-14]** **미매핑 파일의 L5 = 2**(파일 내부 이탈 없으면). 미매핑/out-of-scope 여부는 L5(챕터 내 시험무관 분량)와 분리해 **파일 존치(메타 결정)로 처리**하고, L5는 파일 내부 일관성만 본다. 이 파일은 전 섹션이 VPC로 일관 → L5=2. (대안이던 "미매핑→L5 N/A"는 기각.)
- 클릭형 인터랙티브 SVG(`DetailPanel`+`clickable`) + "시험 단서→정답" 비교표 = 축2 SCHEMA_FEEDBACK와 중복 재현(B6 인터랙티브·decisionTable). 재현 근거 1건 추가.
