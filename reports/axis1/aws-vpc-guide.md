# 축1 리포트: aws-vpc-guide

**모드**: 레거시 / **평가 범위**: 부분 평가 (N/A: L1·L2·L7·L8 — 퀴즈 성분 없음 · **L5 — 축2 범위이탈 근거 유보**) / **판정: 수정** (유효 총점 5/6 = 83.3%)

> 축2 판정: 수정(PrivateLink/게이트웨이 엔드포인트 하이브리드 접근성 일반화 오류 1건). **두 축 종합 = 수정**.
> 성분 태그(축2): 설명 O · 예시 O(인터랙티브 SVG 다이어그램 5종·비교표) · 퀴즈 X · 해설 X / **매핑 챕터: 없음**(VPC는 DVA-C02 out-of-scope, 인벤토리 단계에서 사용자 결정으로 평가 유지).
> ⚠️ **특수 케이스**: 이 파일은 커리큘럼 챕터에 매핑되지 않으며 시험 가이드가 VPC 네트워크 설계를 out-of-scope로 명시. 축2가 「범위 이탈」을 "N/A — L5 판단 유보(참고 근거 없음)"로 명시적 유보함. 아래 L5 처리 참조.

## 수정 지시

1. **[축2 소관 — 종합 게이트]** `SectionConnect` "⚠ 주의" 문단(2353~2356행)의 "VPN이나 DX로 연결해도 VPC 엔드포인트에는 접근할 수 없다" 일반화 오류를 축2 수정 지시대로 게이트웨이/인터페이스 엔드포인트 구분으로 교체. 이 문장이 "시험 함정"으로 제시돼 있어 오류 상태로 학습 시 역효과. (엔드포인트 비교표 2291행에 "온프레미스(VPN/DX) 접근: 게이트웨이=불가/인터페이스=가능" 행 추가.)
2. **[L6 상향, 1→2]** 파일을 유지한다면(인간 결정) 각 개념에 인접 챕터 브리지 추가 — 엔드포인트→"1-1 S3·1-3 DynamoDB의 프라이빗 접근", 보안그룹→"0-2 IAM과 별개인 네트워크 계층 통제", Flow Logs→"5-1 CloudWatch Logs 전송".

## 보충 생성 목록 (결손 성분)

- **[퀴즈·해설 전면 결손]** L1·L2·L7·L8 N/A 원인. 파일 유지 시, 각 비교표의 "시험 단서" 행을 4지선다 문항으로 직접 전환(NACL vs SG DENY, 게이트웨이 vs 인터페이스 엔드포인트, VPN vs DX, 피어링 비전이성). **단, 수정 지시 1의 엔드포인트 접근성 오류 수정 후 문항화**(현 오류를 정답으로 굳히지 않도록).
- **[메타 결정 — 인간]** 파일 자체의 존치 여부. VPC는 시험 out-of-scope이나 인벤토리 단계에서 보존 결정됨. 변환 단계에서 (a) 부록/보너스로 격리, (b) 제외, (c) SAA 대비 자료로 분리 중 인간 판단 필요.

## 반복 약점 메모

- **퀴즈·해설 부재** → L1·L2·L7·L8 N/A (코퍼스 공통).
- **L6 명시 지목 부재** → 코퍼스 전역 반복(전 파일 L6=1).
- **미매핑 파일의 L5 처리 부재**: 아래 스키마 피드백에 앵커 제안.

## 스키마 피드백 요약

- **[신규 앵커 제안]** **커리큘럼 미매핑(out-of-scope-but-kept) 파일의 L5 처리**. 현행 L5 앵커는 축2 범위이탈을 전제하나, 미매핑 파일은 축2가 범위이탈 근거를 제공하지 못함(이 파일에서 명시적 유보). 제안: *"미매핑 파일 → L5 N/A, 유효 만점에서 제외. 파일 존치 자체는 인벤토리/변환 단계 결정"*. 인간 결정 필요(이번엔 N/A 처리, 앵커 미승인 상태이므로 잠정).
- 클릭형 인터랙티브 SVG(`DetailPanel`+`clickable`) + "시험 단서→정답" 비교표 = 축2 SCHEMA_FEEDBACK와 중복 재현(B6 인터랙티브·decisionTable). 재현 근거 1건 추가.
